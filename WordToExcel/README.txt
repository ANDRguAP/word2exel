Word ↔ Excel — перенос таблиц в обе стороны
============================================

Запуск:  python3 app.py   (нужен Python 3.8+, tkinter входит в стандартную поставку)
Установка зависимостей:  pip install -r requirements.txt

ВОЗМОЖНОСТИ
-----------
1. Word → Excel («как есть», режим по умолчанию):
   - переносит ЛЮБЫЕ таблицы из .docx — все найденные, без привязки к шапке;
   - каждая таблица ложится на отдельный лист Excel («Таблица 1», «Таблица 2», …);
   - поддерживаются ОБЪЕДИНЁННЫЕ ЯЧЕЙКИ (по горизонтали и вертикали);
   - числа, записанные текстом, автоматически становятся настоящими числами
     (коды с ведущими нулями, например «007», остаются текстом);
   - ширина столбцов подбирается по содержимому, первая строка выделяется жирным;
   - если указать существующий файл Excel — таблицы добавятся в него новыми листами,
     если не указывать — будет создан новый файл.

2. Word → Excel («разложить по шапке»):
   - данные из Word раскладываются по заголовкам существующего Excel-файла;
   - заголовки сопоставляются «по смыслу» (нечёткое сравнение), порядок столбцов
     в Word и Excel может отличаться.

3. Excel → Word:
   - переносит данные листа (или ВСЕХ листов) .xlsx в документ Word;
   - каждый лист становится отдельной таблицей с рамками (Table Grid);
   - поддерживаются объединённые ячейки, даты и числа корректно форматируются;
   - если целевой .docx уже существует — таблицы дописываются в его конец.

ВАЖНО
-----
- Поддерживаются файлы .docx и .xlsx. Старые форматы .doc/.xls сначала
  пересохраните в Word/Excel как «.docx»/«.xlsx».
- Вложенные таблицы Word переносятся как обычный текст ячейки.
