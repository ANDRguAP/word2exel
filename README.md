# Word ↔ Excel — перенос таблиц в обе стороны

Небольшое десктопное приложение (Python + Tkinter) для переноса таблиц между Word и Excel.
Работает с **любыми** таблицами: без заранее заданной шапки, с несколькими таблицами в документе
и с объединёнными ячейками.

## Возможности

**Word → Excel**
- Переносит все таблицы из `.docx` — каждая становится отдельным листом Excel («Таблица 1», «Таблица 2», …)
- Сохраняет объединённые ячейки (по горизонтали и вертикали)
- Текстовые числа превращает в настоящие числа Excel (коды вида `007` остаются текстом)
- Подбирает ширину столбцов, выделяет шапку жирным
- Умеет дописывать таблицы в существующий `.xlsx`
- Режим «разложить по шапке»: данные из Word раскладываются по заголовкам готового Excel-файла (нечёткое сопоставление, порядок столбцов не важен)

**Excel → Word**
- Переносит данные листа или **всех** листов `.xlsx` в документ Word
- Каждый лист — отдельная таблица с рамками
- Поддерживает объединённые ячейки, даты и числа
- Может дописывать таблицы в существующий `.docx`

## Установка

Требуется Python 3.8+ с модулем Tkinter.

```bash
git clone https://github.com/<ваш-логин>/word-to-excel.git
cd word-to-excel
pip install -r requirements.txt
python app.py
```

**Windows:** при установке Python отметьте `Add python.exe to PATH` и `tcl/tk and IDLE`.
**macOS:** берите сборку с python.org (в ней есть Tkinter). Для Homebrew Python нужен `brew install python-tk`.

## Как пользоваться

1. Выберите направление: **Word → Excel** или **Excel → Word**.
2. Укажите исходный файл (и, при желании, существующий файл-шаблон).
3. Укажите, куда сохранить результат (если не указать — будет создан файл `*_result.xlsx` / `*_result.docx`).
4. Нажмите **▶ ЗАПУСТИТЬ** — в журнале отобразится найденные таблицы, сопоставление столбцов и результат.

## Поддерживаемые форматы

| Формат | Поддержка |
|---|---|
| `.docx` | ✅ |
| `.xlsx` | ✅ |
| `.doc`, `.xls` | ❌ (пересохраните в Word/Excel как `.docx` / `.xlsx`) |

Вложенные таблицы Word переносятся как обычный текст ячейки.

## Технологии

- [python-docx](https://python-docx.readthedocs.io/) — чтение/запись Word
- [openpyxl](https://openpyxl.readthedocs.io/) — чтение/запись Excel
- Tkinter — графический интерфейс (входит в стандартную поставку Python)
